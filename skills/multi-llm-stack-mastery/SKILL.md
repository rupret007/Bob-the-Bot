# Multi-LLM stack mastery

## When
Use whenever choosing, launching, steering, or auditing any of Jeff’s models: **Codex/Astra (ChatGPT)**, **Claude**, **Grok (this Bot + Cloud)**, **Gemini**, **MiniMax**. Pair with [Best LLM for the job](sand-workflow:best-llm-for-the-job) for spend routing, [Codex Goal mastery](sand-workflow:codex-goal-mastery) / [Claude Code mastery](sand-workflow:claude-code-mastery) for deep craft, and [Multi-LLM stack smoke test](sand-workflow:multi-llm-stack-smoke-test) to prove each resource still works.

Jeff 2026-09-22: know how to use each resource and use it well; keep remembering; stay amazing; have a means to test them all.

## Universal conductor rules (all models)
1. **One coding lease per checkout** — never dual-lease Cloud+Codex+Claude on the same tree.
2. **Evidence decides done** — tests, builds, screenshots, tip SHA; never “looks done.”
3. **Outcome → verify → constraints → boundaries → iteration → blocked stop** for long work (same six-part idea across stacks).
4. **Tighten vague goals** instead of spam CONTINUE / “keep going.”
5. **Ping Jeff only for real owner gates** (login, signing, spend raise, feel, physical).
6. **Read real meters** before routing (usage pulse / dashboard) — never invent %.
7. **Heavy coder vs light conductor** — put weight on included coding pools; keep Grok Bot lean when tokens are tight.
8. **Smoke before trust** — after outages/login changes, run Level A (and Level B if Jeff asks) via the smoke-test skill.
